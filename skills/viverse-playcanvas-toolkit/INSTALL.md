# Install

Use this file if you want the shortest possible setup instructions.

## Fastest Option

1. Unzip `viverse-playcanvas-toolkit.zip`.
2. Open the extracted folder itself in VS Code.
3. Keep the folder structure unchanged.

This is the safest option because all bundled links and supporting assets stay in place.

## Merge Into Another Workspace

If you want these skills inside an existing project:

1. Unzip `viverse-playcanvas-toolkit.zip`.
2. Copy the extracted contents into the root of the target workspace.
3. Preserve the folder structure exactly.

The target workspace should contain paths such as:

1. `skills/`
2. `prompts/`
3. `toolkit-capability-catalog.md`
4. `scripts/`

## Do Not Do This

1. Do not copy only `skills/` and `prompts/` by themselves.
2. Do not add an extra wrapper folder around the extracted contents.
3. Do not rebuild the zip with Finder Compress if you want to avoid macOS metadata files.
